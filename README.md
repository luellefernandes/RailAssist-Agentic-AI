# RailAssist 🚆
### Agentic AI-Based Railway Complaint Management System

RailAssist is a proposed AI-powered railway complaint management and passenger safety application developed as part of **HACKSHASTRA 2K26**, a college hackathon at BGS College of Engineering and Technology.

The project focuses on improving the railway passenger experience through technology by bringing complaint management and emergency assistance features together in one platform.

## 💡 Key Features

- **AI-Powered Complaint Management:** An AI-based approach to assisting with railway complaints.
- **SOS Emergency Assistance:** An emergency feature designed to help passengers request assistance.
- **Passenger Tracking:** A tracking feature intended to support passenger safety.

## 🛠️ Tools & Technologies

- **Google AI Studio** – AI development and experimentation.
- **Supabase** – Backend services and data management.
- **Lovable** – UI design and application development.

## 🎯 Project Objective

To explore how Artificial Intelligence can be applied to railway services to improve complaint handling, accessibility and passenger safety.
